# 课程工作台

本地运行的多课程知识工作台。每门课是一个独立项目，录音与课件随时补进来，
由 `lecture-knowledge-pipeline` 技能加工成知识点大纲、图文笔记、知识图谱和可反复训练的题库。

## 启动

首次使用先装依赖、编译一次：

```bash
npm install
npm run build
```

之后每次打开工作台：

```bash
npm start
```

浏览器访问 http://127.0.0.1:8787

开发模式（改前端代码会热更新）：

```bash
npm run dev
```

访问 http://localhost:5173

改完代码想确认没跑偏，跑一次冒烟测试（用临时目录起真服务，建课、建阶段目录、上传归档、越界拦截都过一遍，不动 `courses/`）：

```bash
npm run smoke
```

## 课程存在哪里

课程目录默认在 `./courses/<课程名>/`，每个目录就是这门课的全部资产：

```
course.json          课程信息与时间轴节点
COURSE.md            台账
10_kb/               课程介绍、教学大纲、教材、文献
00_source/           每次课的录音与课件
01_transcript/       转写稿
02_slides/           逐页文本与关键页图
03_align/            页与讲述对齐
04_corrections/      纠错清单
05_supplements/      学科补充
06_outline/          知识点大纲（outline.md / outline.json）
07_notes/            图文笔记、讲课流程、总结
08_graph/            知识图谱
09_quiz/             题库（bank.json）
_jobs/               任务日志
```

想换存放位置，改 `workbench.config.json` 里的 `courseRoot`。

## 配置

`workbench.config.json`：

- `courseRoot` — 课程目录位置
- `calendarRoot` — 校历数据位置，默认 `./calendars`
- `port` — 服务端口，默认 8787
- `codexCommand` — 调用的 Codex 命令，默认 `codex`
- `codexSandbox` — 任务运行时的沙箱模式
- `codexExtraArgs` — 追加给 `codex exec` 的参数

环境变量 `PORT`、`COURSE_ROOT` 可以直接覆盖端口与课程目录，冒烟测试用的就是这两个。

### 关于沙箱

默认值是 `danger-full-access`，因为本机的沙箱助手在 `%USERPROFILE%\.codex\.sandbox-bin`
上无法设置 ACL，`workspace-write` 会直接失败。这个模式下任务里的 Codex
可以读写本机任意文件，界面的「任务」页也会提示这一点。

想收紧成只写课程目录，先用管理员权限执行：

```
icacls "%USERPROFILE%\.codex\.sandbox-bin" /setowner "%USERNAME%"
```

再把 `codexSandbox` 改回 `workspace-write`，重启服务。

## 出题范围怎么写

在「任务」页的附加要求里写，例如：

- `出题范围 CN03 全部，20 道单选、5 道多选，难度中等`
- `把上次做错的再出一遍`
- `第 4 章题量不够，补 15 道`

题目、答案、解析、知识点编号会一起进 `bank.json`，练习页按范围筛选、按错题重练。

## 课程信息怎么来

不用手打。学校通知、教学大纲、课程介绍传上来，工作台会读出课程名、学期、教师、
开课单位和有明确日期的重要节点：

1. 新建课程时先把文件拖进去（也可以建好课之后在「材料」页补传）。
2. 自动跑一次「从文件提取课程信息」，产物是 `10_kb/extracted.json`。
3. 时间轴页会列出读到的内容，每个字段标了依据（文件名 + 段落），可以改。
4. 点「写入课程」才落库。读不准或前后矛盾的地方会单独列在「需要你核实」里，
   例如通知写「开课日期」和「上课时间」对不上，它会提示你去问老师。

想重新读一遍，时间轴页有「重新提取」。

## 课程资料标准

所有课程按同一套七部分结构收集，每门课的 `10_kb/课程资料标准.md` 里有完整说明：

1. 课程信息（代码、中英文名、开课单位、简介、先修要求、学期与起止日期、校历链接）
2. 授课信息（每位教师一条：姓名、邮箱、电话、办公室、答疑时间）
3. 预期学习成果 CILO
4. 考核方式（项目与权重，合计 100%）
5. 课程内容（按原文顺序的主题清单）
6. 周次安排（每周：周次、主题、授课教师、子主题）
7. 教材与参考书

全校通用的附则（考勤规定、考试规则、学生事务服务）不进知识库，原文件留在 `10_kb/` 备查。

大纲通常只写周次不写日期。填好「学期开始」后点「按周次重新生成」，工作台按
「学期起始日 +（周次 − 1）周」把每周算成日期，考核节点会保留不会被覆盖。

## 校历与排课

学期起止、假期、复习周、考试周不靠猜，直接从学校校历读。澳门大学有 .ics 订阅，
时间轴页的「排课」里点「更新校历」就会拉取：

```bash
npm run calendar   # 也可以命令行刷新，结果写进 calendars/
```

地址配在 `calendars.json`，换学年改这里即可。

排课要三样输入：校历给的学期（自动）、你填的每周上课日与时间、以及假期例外的处理方式。
日期算法是 `第 1 教学周周一 +（周次 − 1）× 7 +（上课日 − 1）`。落在假期的周会标红，
你逐条选正常、取消、延期到某天或线上，然后点「按周次写入时间轴」。

## 材料按周归档

录音和课件按周次放进 `00_source/week-01/`、`week-02/`……文件名里带周次的会自动归位，
认不出的单列在 manifest 的「未归周」，不会乱猜。
