# 出题与题库规范

## 题型

默认以选择题为主：

| 题型 | 何时用 | 默认占比 |
|---|---|---|
| 单选 | 概念辨识、脑区与功能配对、方法与指标对应 | 60% |
| 多选 | 多条件并列（某方法的多个局限）、需整体把握的清单 | 25% |
| 判断 | 纠正常见误解，尤其相关与因果、空间与时间分辨率 | 10% |
| 名词解释 / 简答 | 用户明确要求时 | 5% |

用户没说题型时，按上表默认配比，并向用户说明实际采用了什么配比。

## 难度分级

- **识记** — 术语、缩写、定义、脑区名称
- **理解** — 机制解释、指标含义、实验结果说明
- **应用** — 读实验设计、判断结论是否成立、选择合适方法

用户说「难度中等」时按 识记 : 理解 : 应用 ≈ 2 : 5 : 3。题量少于 10 道时偏向理解层。

## 干扰项设计

题库质量的关键。好的干扰项来自**真实存在的混淆**：

1. **同类替换** — 换成同层级同类别概念（另一个脑区、另一种成像方法、另一个 ERP 成分）
2. **常见误解** — 学生真会犯的错（把 fMRI 说成毫秒级时间分辨率）
3. **表述强弱错位** — 把「相关」改成「导致」，把「参与」改成「负责」
4. **条件错配** — 机制对但适用条件错（把某效应说成所有任务都成立）
5. **方向反转** — 常被弄反的配对互换（Broca/Wernicke、P600/N400）

禁止：明显荒谬项、与题干无关项、语法不搭配项、长度或措辞暴露答案的选项。

## 题目格式

人读稿 `09_quiz/quiz-<范围>-<YYYYMMDD>.md`：

```markdown
# 认知神经科学 · 出题卷
- 范围：CN03-02 全部 + CN05-01-03
- 配置：单选 20 · 多选 5 · 难度中等
- 生成日期：2026-09-29
- 题库版本：bank.json @ 48 题

## 一、单选（每题 2 分）

### Q001 ｜ 知识点 CN03-02-01 ｜ 难度 理解 ｜ 单选
关于 Stroop 任务中的冲突代价，下列说法正确的是：

A. 它反映的是反应执行阶段的延迟
B. 它通常以不一致条件的反应时减去一致条件的反应时来度量
C. 它只在视觉通道呈现时才会出现
D. 它与前额叶活动无关，主要反映运动准备

**答案**：B
**解析**：冲突代价刻画的是冲突监测与解决带来的额外加工时间……
**溯源**：PPT p.22；录音 38:10；[补充] Kandel Ch.20

---
```

## 练习模式与速查模式

- **练习模式（默认）**：先只给题干与选项，答案、解析、溯源写进同目录的 `answers-<范围>-<YYYYMMDD>.md`，用户作答后再给。
- **速查模式**：用户明确说「直接给答案」时，答案与解析跟在每题下方。

不要擅自默认速查模式——用户的目标是反复训练。

## bank.json

```json
{
  "course": "认知神经科学",
  "updated": "2026-09-29",
  "items": [
    {
      "id": "Q001",
      "type": "single",
      "stem": "...",
      "options": {"A": "...", "B": "...", "C": "...", "D": "..."},
      "answer": ["B"],
      "explanation": "...",
      "pointIds": ["CN03-02-01"],
      "difficulty": "理解",
      "sources": ["PPT p.22", "录音 38:10"],
      "isExtension": false,
      "created": "2026-09-29",
      "attempts": 0,
      "wrongCount": 0
    }
  ]
}
```

字段约定：

- `answer` 一律用数组，多选题放多个键，便于统一处理
- `pointIds` 可多个；跨知识点的题都要列
- `isExtension` 为 `true` 表示超纲拓展题，抽题时可排除
- `attempts` / `wrongCount` 由用户反馈后更新，用于错题重练
- `type` 取值：`single`、`multi`、`truefalse`、`short`

## 出题前必做

1. 读 `bank.json`，列出本次范围内已出过的题干与知识点
2. 同一知识点再出题必须换角度：换情境、换考查机制、换干扰项来源，不能只改数字
3. 单次超过 30 道时分批生成、逐批写盘，避免中途失败丢全部

## 出题后必做

1. 自检与既有题是否重复
2. 更新 `bank.json` 的 `updated` 与题量
3. 在 `COURSE.md` 记录本次范围、题量、文件路径
