# 课程知识流水线

把一次课程的两路输入——**录音轨**和**课件轨**——加工成可长期复用的知识资产：可溯源的大纲、题库、图谱和笔记。

## 铁律

这些约束在任何阶段都不放宽：

1. **不静默改写。** 转写稿里的可疑内容只做标注和纠错建议，不动原文；低置信项标「待老师确认」。
2. **一切可溯源。** 每个知识点有稳定 ID 和来源（PPT 页码或录音时间戳）；每条补充内容带出处；每道题带知识点 ID。
3. **课堂原话与补充内容分开写。** 补充内容必须落在独立的补充块里，不能混进「老师讲了」的叙述。
4. **题目与解析默认分离。** 走练习模式：先只给题目，用户作答后再给答案与解析。
5. **不重复出题。** 出题前先查题库，同一知识点再出题必须换考查角度。

## 工作区

每门课一个目录，产物按阶段分开放，方便增量更新：

```
<课程名>/
  COURSE.md          台账：输入清单、阶段状态、待确认项、出题记录
  00_source/         原始录音、课件
  01_transcript/     转写稿（带时间戳）
  02_slides/         逐页文本 + 关键页 PNG
  03_align/          页与讲述的对齐表
  04_corrections/    纠错清单
  05_supplements/    学科补充（带出处）
  06_outline/        知识点大纲（.md 人读 / .json 机器读）
  07_notes/          图文笔记、详实大纲、总结、讲课流程
  08_graph/          知识图谱
  09_quiz/           题库与每次出题稿
```

用 `scripts/init_course.py` 建立，不要手工拼路径。

## 阶段

完整步骤、判定条件和质量门见 [references/pipeline.md](references/pipeline.md)。主干：

0. **盘点** — 收齐录音、课件、已有转写稿，确认课程名与学科方向，建工作区。
1. **课件轨** — PPTX/PDF 逐页提文本；关键页渲染 PNG；扫描件走 OCR。
2. **录音轨** — 转写并保留时间戳；需要区分师生时启用说话人分离。
3. **对齐** — 按时间戳把讲述切到对应页，形成「页-讲述」对照；对不上的标低置信。
4. **纠错** — 逐条列出 ASR 误识别、数字单位错误、口误与前后矛盾、课件与讲述冲突，每条给依据与置信度。
5. **补充** — 对讲得含糊或一带而过的知识点做学科补充，查文献或教科书并标出处。
6. **大纲** — 生成三级知识点结构，每个知识点一个稳定 ID。
7. **出题** — 用户按大纲选范围与数量，生成题目、答案、解析，累积进题库。
8. **图谱与流程** — Mermaid 知识图谱 + 讲课流程时间线。
9. **笔记** — 图文并茂笔记、详实大纲、总结。
10. **维护** — 题库统计、错题重练、薄弱知识点补题。

阶段之间可以中断，产物落盘即算完成；恢复时先读 `COURSE.md` 判断从哪继续。

## 交互关口

课程信息一律从学校的课程大纲与通知文件里提取，不靠手填。字段结构见
[references/syllabus-standard.md](references/syllabus-standard.md)：只有课程名可以先用临时名字，
其余字段——课程代码、中英文名、开课单位、简介、先修要求、授课教师、学习成果、考核方式、
课程内容、周次安排、教材与参考书——都由文件读出，用户确认后才写入课程。

**只有一处必须停下来等用户：第 6 步做完之后。** 大纲生成后把它交给用户，等用户圈定范围与数量，再进入出题。

其余阶段按用户当次的要求推进，不必逐段确认。用户只想要笔记时可以跳过出题，用户只想要题时可以跳过图谱和详细笔记，但**纠错和溯源不能跳**。

范围请求的常见形态：

- 「CN03 全部 + CN05-02，20 道单选 5 道多选，难度中等」
- 「把上次错的再出一遍」
- 「第 4 章题量不够，补 15 道」

## 出题

题型、题目与题库的数据结构、难度分级、干扰项设计规则见 [references/quiz-design.md](references/quiz-design.md)。用户要求以选择题为主；名词解释、简答、判断题为可选补充。

认知神经学的高频易错点与干扰项素材见 [references/cogneuro-errors.md](references/cogneuro-errors.md)。学科不是认知神经学时，先按同样方法整理一份本学科易错点清单，再出题。

## 脚本

- `scripts/init_course.py <课程目录> --name <课程名>` — 建工作区与台账。
- `scripts/bank.py add|stats|pick|dupes|record` — 题库累积、覆盖度统计、按知识点抽题、重复检测、错题记录。

运行脚本前先看 `--help` 确认用法；脚本报错先修再用，不要绕过。

## 成品落盘

产物写进对应阶段目录，文件名带知识点 ID 或日期，避免覆盖历史版本。用户要 Word/PDF 排版稿时用 `documents` 插件，要可点击的交互式图谱时用 `visualize` 插件。
